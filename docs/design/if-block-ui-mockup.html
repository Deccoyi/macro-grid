If / Otherwise / End in the action list

Static mockup for review. One spine joins the three rows into a block. Steps inside sit in a lane; every gap is an insertion slot.

Behaviour in this mockup

  • Slots are real buttons: Tab reaches them, Enter opens the action picker, and the pick lands at that slot.
  • Gaps between top-level steps stay quiet (plus appears on hover or focus). Gaps inside a block show a faint plus, so the target is discoverable.
  • Drag starts from the grip (⋮⋮) on a step or an If header. Dragging an If carries its whole block; its own inside is not a target.
  • Saved data stays a flat list. The spine, lanes and slots are drawing only.
  • Colours come only from theme tokens. The one accent spine marks If; Otherwise uses the neutral border so only one thing is loud.
