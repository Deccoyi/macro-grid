# Getting help

Macro Grid is alpha software made by one maintainer, so answers can take a few days. This page says where to go.

| You want to | Go to |
|---|---|
| Ask how something works, or ask for advice | [Discussions, Q&A](https://github.com/Deccoyi/macro-grid/discussions/categories/q-a) |
| Share an idea or suggest an improvement | [Discussions, Ideas](https://github.com/Deccoyi/macro-grid/discussions/categories/ideas) |
| Show a profile, a layout or a setup you made | [Discussions, Show and tell](https://github.com/Deccoyi/macro-grid/discussions/categories/show-and-tell) |
| Report something that is broken in the Windows server, the editor, the browser deck and the installer | [A new issue](https://github.com/Deccoyi/macro-grid/issues/new/choose): pick the form, or the plain-text version if you prefer to just fill in text |
| Report a security problem | The [private form](https://github.com/Deccoyi/macro-grid/security/advisories/new). Never in a public issue or discussion. See `SECURITY.md`. |

Something else is broken? The other parts of Macro Grid have their own pages:
[server and editor](https://github.com/Deccoyi/macro-grid/issues/new/choose),
[phone app](https://github.com/Deccoyi/macro-grid-client/issues/new/choose),
[plugins](https://github.com/Deccoyi/macro-grid-plugin/issues/new/choose).

Before you write: the website has a guide and a FAQ, and the existing issues and discussions may already have your answer.
