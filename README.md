# Macro Station

Kendi ağınızda çalışan, Stream Deck benzeri bir masaüstü + telefon makro sistemi. Windows'ta çalışan bir sunucu; telefonunuzda (yakında) veya sunucunun kendi düzenleyicisinde tasarladığınız grid'e oturan butonlar, slider'lar ve widget'lar üzerinden klavye kısayolları çalıştırır, canlı sistem verilerini (CPU, RAM, saat...) gösterir ve koşullu (dinamik) stillerle tepki verir.

## Ne yapar?

- **Sunucu** (Windows, sistem tepsisinde çalışır): profilleri/sayfaları/widget'ları JSON olarak saklar, WebSocket üzerinden (port 9820) bağlı cihazlara canlı yayın yapar, klavye kısayolu / metin yazma / uygulama-URL açma / sayfa-profil geçişi gibi aksiyonları çalıştırır.
- **Editör** (sunucunun kendi penceresinde, WebView2 ile): grid üzerinde sürükle-bırak widget tasarımı, renk/ikon/animasyon stilleri, **koşullu stil sistemi** ("CPU %50'yi geçerse kırmızı yanıp sönsün" gibi kurallar — tamamen veri tabanlı, kod çalıştırmaz), aksiyon atama.

Haberleşme yalnızca **yerel ağ (LAN)** üzerinden yapılır; internete açık bir servis değildir.

## Gereksinimler

- **.NET 10 SDK**
- **Node.js 20+** (yalnızca editörü geliştirme modunda çalıştırmak isterseniz)
- Windows 10/11 (sunucu şu an yalnızca Windows'ta çalışıyor — WebView2, WinForms tepsi uygulaması ve Windows API'lerine bağımlı)

## Çalıştırma

```bash
# Sunucu (tepsi uygulaması + WebSocket + editör API'si)
dotnet run --project src/MacroStation.Host

# Editörü geliştirme modunda çalıştırmak isterseniz (opsiyonel — normalde tray'den "Düzenleyiciyi aç" yeterli)
cd editor
npm install
npm run dev

# Testler
dotnet test
```

Sunucu ayaktayken tepsi simgesinden **"Düzenleyiciyi aç"** ile grid/profil editörünü açabilirsiniz.
