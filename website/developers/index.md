# For developers

Everything else on this site is for people who use Macro Grid. This page is for people who want to build it, extend it or contribute.

| Repository | What it is |
|---|---|
| [macro-grid](https://github.com/Deccoyi/macro-grid) | The Windows server, the editor, the browser deck and the plugin SDK. |
| [macro-grid-client](https://github.com/Deccoyi/macro-grid-client) | The Android app. |
| [macro-grid-plugin](https://github.com/Deccoyi/macro-grid-plugin) | The official plugins. |
