# FAQ

## Does it work on Mac, Linux or iPhone?
The server needs Windows 10 or 11. The phone app is Android only for now; any device with a browser can use the browser deck.

## Does it need the internet or an account?
No. Everything stays on your local network.

## Is there a cloud sync?
No. Export a profile to a `.msprofile` file to move it.

## Can several phones connect at once?
Yes. Each paired device can open its own profile.

## Can I use it in a browser instead of the app?
Yes: `http://<PC address>:9820/deck/`. The phone app adds kiosk mode, caching and gestures.

## Can I embed a web page or a chat?
Not yet. The **Web** and **Plugin** widget types are placeholders.

## Which language is it in?
The editor is in Turkish (default) or English. The phone app and browser deck are currently Turkish only. Some built-in action names and the tray menu are Turkish only.

## Can I make my own plugin?
Yes, in JavaScript or C#. See the [plugin documentation](https://deccoyi.github.io/macro-grid-plugin/).

## Is it safe?
It is alpha software written by an AI, meant for a trusted network. Read [Security](/guide/security).

## Where do I report a bug?
[GitHub Issues](https://github.com/Deccoyi/macro-grid/issues). Include the logs from `%AppData%\MacroGrid\logs\`.
