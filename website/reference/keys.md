# Shortcut key names

In the **Shortcut** action you normally click the field and press the keys. The stored text is keys joined by `+`, for example:

```text
ctrl+shift+s
alt+f4
win
ctrl+plus
```

- **Modifiers:** `ctrl` (`control`), `shift`, `alt`, `win` (`windows`, `meta`, `cmd`).
- **Common keys:** `enter` (`return`), `escape` (`esc`), `tab`, `space`, `backspace`, `delete` (`del`), `insert` (`ins`), the arrow keys `up`, `down`, `left`, `right`, `printscreen`, `numlock`.
- **Punctuation** is spelled out: `plus`, `minus`, `comma`, `period`, `semicolon`, `slash`, `backslash`. The literal `+` key is written `plus` because `+` separates keys.
- A lone modifier such as `win` is sent as a plain key press.
- Names are not case sensitive.
